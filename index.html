三个趋势：
1. 程序阅读最重要。R1–R5 合计约占选择题的 40%，2023 年改用 C++ 后，“整数除法、负数取模、++/--、三目运算”这类语法陷阱明显变多。
2. 数学类稳定占两成。排列组合、概率（2020 年起每年约 2 题）、数论。概率题往往是选择题里最难的几道。
3. 计算机常识题越来越少。2012–2018 年平均每卷 4 道，近 6 年只剩 1 道左右，不用花太多时间。填充题里的位运算和数学技巧（F6）、前缀和（F3）变多了。

应试技巧

  • 选择题全部要填。答错不扣分，不会也要猜一个。
  • 卷一 50 分钟、卷二 40 分钟，连着考。模拟考时也按 50 ＋ 40 分钟计时。卷一做完先别翻卷二，先检查卷一的填写题。
  • 卷二只答 C++ 版，并在答题纸上标明。两种都答或没标明，按 C++ 版计分。
  • 先易后难。选择题前 10 题一般最容易；概率、博弈、图论题拿不准就先标记，最后再回来。
  • 跟踪程序一定写表。每个变量一列，每轮循环一行，不要在脑子里记。
  • “执行 2024 次”先找循环节。列出前十几步，看从哪里开始重复，再取模。
  • 负数和溢出是常见陷阱。看到 %、/、很大的数时，先想一想负数和 int 范围（约 ±21 亿）。
  • 填充题一格一个字符。答案不能超过给的格子数；同一个空分成几部分时，全对才给分。写完把答案代回程序走一遍。
  • 构造题只要满足条件就给分。选最简单、最好检查的答案。

C++ 语法陷阱

R1 K1
必做 0 / 17加练 0 / 16
要会的知识点
  • 整数除法向 0 取整：5/4=1，-7/2=-3；5/4.0=1.25
  • 负数取模：-7%3 = -1（符号跟被除数）
  • int 是 32 位：最大 2147483647，溢出会变成负数
  • i++ 与 ++i；while(tc--) 与 while(--tc) 的差别
  • 三目运算 a?b:c；&& 比 || 优先
  • 悬挂 else（else 跟最近的 if）；for 后面没加大括号只管一句
  • char 是 1 字节 / 256 种值；bool、float 能存什么

怎么练：每道题都在电脑上把代码跑一遍，验证自己的判断。负数除法、取模和溢出最容易错，把错的例子抄进错题本。
